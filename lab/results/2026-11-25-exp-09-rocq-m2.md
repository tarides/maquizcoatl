## The statement change (a definition changed for the proof)

`Statement.v`'s `main_theorem_statement` now reads `forall r s p,
NoDup (groups r) -> p <= length s -> ...` (the rest unchanged), with
`groups r` the group numbers of `r` in pre-order (defined in
`Statement.v`). Reason: the AST type allows a group nested in a group
with the same number, and then the VM and the semantics disagree. In
`rocq/Proof.v`, checked by `reflexivity`:

    nested_same_group_vm  : vm 100 (compile (Group 1 (Cat (Lit [97]) (Group 1 (Lit [98]))))) 1 [97; 98] 0
                            = Match 2 [Some (1, 2)]
    nested_same_group_sem : sem 100 (Group 1 (Cat (Lit [97]) (Group 1 (Lit [98])))) [97; 98] 0
                            = Match 2 [Some (0, 2)]

The inner `OP_MEM_START 1` overwrites the start that the outer one
wrote, while the semantics' outer `AClose 1 0` writes last. No pattern
in fragment syntax has this shape: the parser numbers groups by their
opening parenthesis (`FRAGMENT.md` section 1), so the hypothesis holds
for every case, and it is what "pattern of the fragment" means in
`FRAGMENT.md` section 7 (now said explicitly). The proof uses it only
through the invariant `uniq` (no group number repeats on the pending
path). The theorem may well hold for repeated numbers that are not
nested; that was not explored. It is a statement change, so it is
raised on issue #4 for the maintainer; F\* and Verus will transcribe
the same hypothesis.

checks in the run. Per-lemma counts are in
[effort.tsv](../09-representative-proof/effort.tsv). The failures were
all local and quick to fix: arithmetic forms of addresses (`pc + 0`,
`S (S pc + clen a)` against `pc + clen a + 2`), `simpl` unfolding

lemma statement or proof strategy had to change after it was written.

Statements of the main lemmas (Rocq, abridged only in layout):

- **(a)** `length_comp : forall r pc eid push, length (comp r pc eid push) = clen r`;
  the `code_*` lemmas read the instructions of each construct off
  `code_at code pc (comp r pc eid push)`, e.g. for a nullable star body
  `code_star_null`: `IPush (L + clen a + 4)` at `L`, `IEmptyStart eid` at
  `S L`, the body at `L + 2`, `IEmptyEnd eid` at `L + 2 + clen a`,
  `IJump L` at `L + 3 + clen a`; `code_compile r`: the pattern's code
  at 0 and `IEnd` at `clen r` in `compile r`.
- **(d), semantics** `ct_total : forall acts pos g, exists f t,
  compute_tree f s acts pos g = Some t`, by lexicographic induction on
  `(|s| - pos, W pos acts)`, `FRAGMENT.md` section 4's measure, with
  the weight of `ACheck p0 a` 1 when `pos = p0` and `size a + 3`
  otherwise (no invariant `p0 <= pos` was needed);
  `ct_mono : compute_tree f s acts pos g = Some t -> f <= f' ->
  compute_tree f' s acts pos g = Some t`; `ct_det` (two fuels give the
  same tree); `clen0_fm : clen a = 0 -> compute_tree f s (ARe a :: k)
  pos g = Some t -> exists f' t', compute_tree f' s k pos g = Some t'
  /\ first_match t' = first_match t`.
- **(b) + (c)** `sim : forall f acts pos g t, compute_tree f s acts pos
  g = Some t -> forall pc stk P X m, rep pc acts pos stk P X -> capsrel
  m g (cls acts) X -> uniq acts -> simres (cls acts) X pc pos m stk t`,
  where `simres` says: if `first_match t = Some (e, g')`, the VM from
  `St pc pos m stk` reaches `OP_END` at `e` with captures `m'` such that
  `rv (mget k m') = gget k g'` for every `k`; if `None`, it behaves as
  the failure of `stk` (`fails stk m1`) for some `m1` with `meq (cls
  acts) X m1 m`. `rep`, `capsrel`, `meq` and `uniq` are described in
  `FRAGMENT.md` section 8 ("How Rocq closed it"). The Star and ACheck
  cases of `sim` are lemma (c): the nullable body pushes `EAlt` then
  `EEmptyStart id pos`, and `ACheck pos a` is `OP_EMPTY_CHECK_END id`
  reading that entry; a body that cannot match the empty string has
  only the `OP_JUMP`, and `rep` carries `p0 + minlen a <= pos` so that
  the semantics' check cannot leave the loop there. The induction is on
  the fuel, not on the measure: the measure enters only through
  `ct_total`.
- **(d), VM** `vm_complete : NoDup (groups r) -> compute_tree f s [ARe r]
  p [] = Some t -> exists n, vm n (compile r) (ncap r) s p = (the
  semantics' result read off t)`, from `sim` at `pc = 0`, stack
  `[EFinish]`, `X = topg r`; no step bound was needed, because `exec` is
  "some fuel makes `run` return".
- **(e)** `main_theorem : main_theorem_statement`, from `ct_total`,
  `vm_complete`, `ct_det` and `vm_det` (two fuels that both finish give
  the same VM result).

Lemmas remaining for run 5: **none**. The Rocq theorem is closed.
