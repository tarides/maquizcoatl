# Experiment #8, entry 3: subexpression calls with the nest limit

**What.** The calls semantics of `lab/08-hard-features/SEMANTICS.md`
(section 1: a first-order backtracking matcher whose state carries the
nest depth; the limit is a parameter, default 20; the definition site of
a called group is a call) written in Rocq, Lean 4, F\* and Verus, run on
the 15 calls cases, with lemma C proved: every result is produced with
nest depth at most the limit at every step.

**Why.** Step 4 of the plan, first feature (decision 2: calls first, in
every tool). Calls appear in 18 of 82 VS Code grammars (experiment #1).

## Automation failures and manual help

- **Rocq** (`rocq/Calls.v:62-80`): the proof is one case analysis with a
  `repeat match goal` destruct script; `eapply IH` left evar goals in
  an unexpected number, replaced by `refine (IH _ _ _ _ _ _ _ _ H); lia`;
  the call case needs the bridge `Nat.leb_gt` before `lia` (line 77).
- **Lean** (`lean/Calls.lean:64-112`): written by hand, one `match` arm
  per stack head with `simp only [m] at hp`, `split at hp` and
  `omega`; checked first time. No automation failure.
- **F\*** (`fstar/Calls.fst:59-88`): the lemma mirrors the definition
  with one recursive call per branch; for the two branching cases it
  needs `append_memP` and `Classical.move_requires` on both branches
  (lines 71-77). One type annotation on a case subject (`s4 : list
  nat`). No SMT timeout.
- **Verus** (`verus/calls.rs:99-157`): same mirrored structure with an
  auxiliary lemma `lemma_app_mem` (proved by induction); the
  single-result case needs `reveal_with_fuel(mem, 2)` (line 109;
  without it, "postcondition not satisfied", checked by ablation).

Computability help: the fuel (all four). No tool needed a lexicographic
measure: every tool accepts `decreases f` on the fuel.

## Analysis

All four tools state, run and prove the calls feature in a few seconds,
and the nest limit as a parameter costs nothing in any of them. The
interactive tools need a hand-written case analysis (Lean longer, Rocq
shorter thanks to a tactic loop); the SMT tools need the lemma to mirror
the definition with explicit recursive calls and a membership-in-append
lemma. Verus's spec language pushed the semantics to an own list type
(`L<A>`) so that the interpreter can run cases, which makes it the
largest encoding. The default limit is the code's 20, not
`doc/API`'s 24 (deviation candidate D-08-1, [entry 2](2026-11-19-exp-08-corpus.md)).
Not covered: captures, the never-ending-recursion check (a precondition),
interaction of calls with empty loops beyond the corpus.
