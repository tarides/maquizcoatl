# Experiment #8, entry 4: absent operator

**What.** The direct absent semantics of `SEMANTICS.md` section 2 (a
right-range register; repeater, expression, stopper and range clear;
absent patterns absent-free) in the four tools, run on the 11 absent
cases, with lemma A proved: for every end `e` of the repeater started at
`i`, no position in `[i, e)` starts an absent match.

**Why.** Second feature of step 4. The absent operator is used by 2
triples of experiment #1's corpus and no formal work covers it.

## Provenance

Sources `lab/08-hard-features/{rocq/Absent.v, lean/Absent.lean,
fstar/Absent.fst, verus/absent.rs}` at commit `27eea1c`; timed runs
`timed-{1,2,3}`. Host, versions, cap and CPU set as in [entry 1](2026-11-19-exp-08-setup.md). Times: median of three sequential runs of `lab/08-hard-features/check.sh <tool> <Feature> <run>` (`timed.sh`), wall-clock of the whole file check including tool start-up; peak RSS is `/usr/bin/time -v`'s maximum resident set size of the largest single process (for Verus, `rust_verify`; Z3 runs in a separate process and is not included). Load average at the timed runs: 2.1-4.2 (experiment #5's install on other cores). Raw logs, `/usr/bin/time` output, load and assumption-check output per run: [raw/timed-1/](2026-11-19-exp-08-raw/timed-1/), `timed-2/`, `timed-3/`; line counts by `lab/08-hard-features/loc.py` ([raw/loc.tsv](2026-11-19-exp-08-raw/loc.tsv)). Native computation (`native_decide`, `native_compute`) is used nowhere, so no `Lean.ofReduceBool` axiom appears; every case and every main lemma is checked by the kernel (Rocq `vm_compute`, Lean `decide +kernel`), by F\*'s normaliser (`assert_norm`) or by Verus's interpreter (`by (compute_only)`). Fuel (1000 steps) is used by all four tools; it is computability help for Rocq and Lean, and is kept in F\* and Verus so that the four definitions are the same (SEMANTICS.md, "Common design").

## Automation failures and manual help

- **Rocq, automation failure** (`rocq/Absent.v:42-49`, lemmas at 92-121): with `scan`
  calling `occ` (a 1000-fuel base matcher) directly, the kernel check
  at `Qed` of `scan_none` unfolded the fuel and did not finish (killed
  after more than 60 s; the tactics themselves took milliseconds). Fixed
  by making `scan` generic in the predicate, so the lemmas never
  mention the matcher.
- **Lean**: no automation failure (one tactic-syntax fix).
- **F\***: none; verified at the first attempt.
- **Verus** (`verus/absent.rs:139`): `reveal_with_fuel(mem, 2)` again,
  for the singleton list.

## Analysis

The register-carrying direct semantics is short in every tool and agrees
with the C library on the 11 cases, including the three pairs that go
through different C code paths (`(?~abc)` vs `(?~|abc|\O*)`, see
[entry 2](2026-11-19-exp-08-corpus.md)). Lemma A is simple (two
inductions); the only real failure is Rocq's kernel reducing the fuel
during conversion, which no other tool hit. Not covered: nested absent
functions (`test_utf8.c:850`, out of scope by the plan), a proof that
the direct semantics equals the C desugaring (follow-up).
