## Lemmas: all closed, none open

Plan order (a)-(e). F\* needs no existential where Rocq used one: the
proof's central items are **total functions that return their
witnesses** (the number of VM steps and the final captures, or the
fuel), refined by their postcondition, which is the F\* idiom for an
existential proof. By the plan's definition (step 6) a lemma is a
top-level `let` whose type is a `Lemma`, so these functions are listed
apart ("proof functions"). Attempts: checks that failed in the item,
plus the successful one.

43 lemmas and 17 proof functions, all closed; 7 failed checks. The
failures: `length_comp` twice (an `SMTPat` that did not fire on the
polymorphic `length`, then fuel 2 too low for the nullable-star layout,
fixed with `--fuel 4` on that lemma); `code_at` once (missing
`decreases` clauses); `choice` once (binder syntax); `case_group` once
(the group's continuation is represented at `pos + minlen a`, as Rocq's
`apply le_n` had chosen, not at `pos`); `vm_complete` once (an equation
not derived after a `match` statement, fixed by one return per branch);
and `case_cat` once, after the proof had closed, when the module's
rlimit was lowered from 20 to 10: `case_cat` needs 20 (its largest query
used rlimit 10.24), the rest needs 10. No statement or proof strategy
changed after it was written.

Statements of the main items (F\*, abridged only in layout):

- **(a)** `length_comp r pc eid push : Lemma (length (comp r pc eid push)
  == clen r)`; `code_at code pc l` is a recursive proposition ("`l` sits
  in `code` at `pc`"), and the `code_*` lemmas read each construct's
  instructions off `code_at code pc (comp r pc eid push)`, as in Rocq;
  `code_compile r : Lemma (code_at (compile r) 0 (comp r 0 0 false) /\
  nth (compile r) (clen r) == Some IEnd)`.
- **(d), semantics** `fuel_of s acts pos g : Pure nat (requires True)
  (ensures fun f -> Some? (compute_tree f s acts pos g)) (decreases
  %[rem s pos; ww pos acts])` on `FRAGMENT.md` section 4's measure
  (`ACheck p0 a` weighs 1 at `pos = p0`, `size a + 3` otherwise);
  `ct_total` states the existential from it; `ct_mono : Some?
  (compute_tree f ...) /\ f <= f' ==> compute_tree f' ... ==
  compute_tree f ...`; `ct_det`; `clen0_fm : clen a = 0 /\ Some?
  (compute_tree f s (ARe a :: k) pos g) ==> Some? (compute_tree f s k
  pos g) /\ first_match (that) == first_match (the former)` (Rocq's
  version is an existential over the fuel; this one keeps the same fuel).
- **(b) + (c)** `sim code s f acts pos g t pc stk p x m (h : rep code pc
  acts pos stk p x) : Pure (nat & mcaps) (requires compute_tree f s acts
  pos g == Some t /\ capsrel m g (cls acts) x /\ uniq acts) (ensures fun
  o -> simres code s (cls acts) x pc pos m stk t o) (decreases %[f;
  h])`, where `simres` says: if `first_match t = Some (e, g')`, the VM
  from `St pc pos m stk` reaches `Halt (Some (e, snd o))` in exactly
  `fst o` steps (`exe`) and `rv (mget k (snd o)) == gget k g'` for every
  `k`; if `None`, after `fst o` steps it is where `fail stk (snd o)`
  leads, with `meq (cls acts) x (snd o) m`. `rep`, `capsrel`, `meq`,
  `uniq`, `fresh` are Rocq's, with `rep` an indexed inductive type and
  the open groups looked up by `cget` instead of `In`. `sim` handles the
  `OP_JUMP` case itself and passes the induction hypothesis at `f - 1`
  as a function to one function per construct; the Star, `ACheck` and
  `choice` functions are lemma (c).
- **(d), VM** `vm_complete r s p f t : Pure nat (requires nodup (groups
  r) /\ compute_tree f s [ARe r] p [] == Some t) (ensures fun n -> vm n
  (compile r) (ncap r) s p == sem_of r t)`, from `sim` at `pc = 0`,
  stack `[EFinish]`, `x = npg r false @ []`, through `exe_run` (`exe n st
  == Halt r ==> run n ... st == Some r`).
- **(e)** `main_aux` (the statement's body for one `r`, `s`, `p`, from
  `fuel_of`, `vm_complete`, `ct_det` and `vm_det`) and
  `main_theorem () : Lemma main_theorem_statement` by
  `FStar.Classical.forall_intro_3`.

The two counterexample checks of `rocq/Proof.v` are transcribed as
`assert_norm`s (`nested_same_group_vm`, `nested_same_group_sem`): the
VM gives `Match 2 [Some (1, 2)]`, the semantics `Match 2 [Some (0, 2)]`.

Lemmas remaining for runs 8-9: **none**. The F\* theorem is closed.
