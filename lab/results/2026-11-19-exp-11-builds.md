# exp-11 builds: seven engine columns from pinned sources

## What

Every engine and harness of experiment #11 built on the bench
host from pinned sources, with the build commands logged
(`2026-11-19-exp-11-builds.log`, paths shown as `<bench>`, the
experiment directory in the bench host's home). Oniguruma `f95747b` is
built twice, with direct-threaded and with switch dispatch, and a probe
compiled with each build's flags shows which dispatch each one compiled.

## Why

Criterion 1 of issue #2: every engine builds from a pinned version, with
recorded build commands, and the notebook shows the dispatch actually
compiled by each Oniguruma build (Decision 2 on the issue, the switch
column gives #10 its dispatch number).

## Analysis and open questions

- Criterion 1 is met: seven columns built from pinned versions, commands
  logged, and the two Oniguruma builds verifiably compile different
  dispatch code.
- Deviation from the plan's layout: the experiment directory on the bench
  host is `~/maquizcoatl-work/exp/11-perf-baselines/` (the pipeline's
  convention) instead of `~/maquizcoatl-work/e11/`; scripts take it from
  `BENCH` in `env.sh`.
- opam 2.1.5 built the switch without trouble; the fallback in the plan's
  risks was not needed. opam warns that 2.5.2 has security fixes; the
  system opam was not changed (no root).
