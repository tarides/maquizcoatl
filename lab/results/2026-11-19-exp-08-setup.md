# Experiment #8, entry 1: toolchains, C builds, tools kept

**What.** Toolchains for the four tools of experiment #8 on the bench host
(Rocq, Lean 4, F\* with Pulse reused from experiment #7; Verus installed
by this experiment), the two out-of-tree C builds of `f95747b` (Debug and
ASan/UBSan), and the smoke tests that validate the memory cap.

**Why.** Step 1 of `plans/08-hard-features.md`. Maintainer decision
(issue #12, relayed in the run comment): run now, without waiting for
experiment #5; **all four tools are kept** (Rocq / stack A, Lean 4 /
stack B, F\* with Pulse / stack C, Verus / stack D). If experiment #5
later eliminates a stack, the results of that tool stay in this record
but are marked as concerning an eliminated stack.

## Provenance

- Bench host: AMD EPYC 7502P (64 logical CPUs, 503 GiB RAM), Linux
  6.8.0-100-generic, Ubuntu 24.04.5 LTS. Checks pinned to CPUs
  16-23,48-55 (`taskset`), `nice -n 10`, away from experiment #11's
  timing cores (4-7,36-39) and from experiment #5's install, which ran
  at the same time on CPUs 8-13,40-45. At most one check at a time.
- Memory cap: `systemd-run --user --scope -p MemoryMax=32G
  -p MemorySwapMax=0` (cgroup v2), timeout 1800 s per check
  (`lab/08-hard-features/check.sh`). Every check stayed under 600 MB.
- Versions ([raw/provenance.txt](2026-11-19-exp-08-raw/provenance.txt)):
  Rocq 9.3.0 (OCaml 5.4.1 switch `provers`), Lean 4.36.0, F\*
  2026.11.15 (commit `b92b0f87ce32`, default Z3 5.3.0), Verus
  `0.2026.11.02.8bf68ee` (Rust 1.99.1, bundled Z3 4.16.0), GCC 13.3.0,
  CMake 3.28.3, Python 3.12.3.
- Commands: `BENCH_WORKDIR=<bench-workdir> lab/08-hard-features/setup.sh
  verus` then `... setup.sh onig`, run under `nice -n 10 taskset -c
  16-23,48-55`. Verus is installed once in `<cache>/verus` with its Rust
  toolchain in `<cache>/rustup` and `<cache>/cargo`, and an env file
  `<cache>/verus-env.sh`, for reuse by experiment #5.
