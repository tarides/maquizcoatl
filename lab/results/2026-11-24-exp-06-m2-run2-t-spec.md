# Experiment #6, milestone 2, run 2: T_spec of the S2 semantics (Rocq, Lean 4, Why3, F\*)

**What.** `T_spec` of the S2 semantics, as run 2 left it, for Rocq
(OCaml target), Lean 4 (C target), Why3 and F\* (OCaml targets).
Check, extraction and compile are timed separately, with the median of
three clean runs, all four provers in one series and with milestone 1's
method. Why3 and F\* are measured again because DEV-008 changed one
line of their semantics, and because one series makes the experiment #7
settling like for like.

**Why.** Question 2 of issue #28 (plan step 9, work package F). The
[settling entry](2026-11-24-exp-07-verdicts-settled-m2.md) reads these
figures.

## Provenance

As the [run 2 throughput entry](2026-11-24-exp-06-m2-run2-throughput.md)
(`series-m2-2a.sh r2`, scripts at `e293368`, last series 16:41-16:48
UTC, pinned, 1-minute load 1.00-1.35). Each run uses a fresh build
directory. The table module is copied in and built untimed first, then
kept, so the timed steps do not rebuild it, as plan step 9 asks:

- Rocq (`rocq/rocq2.sh tspec`): untimed, `rocq compile Tables.v`, then
  `ExtractTables.v` and `ocamlopt -c tables.ml`. Timed:
  `rocq compile -R . S Spec2.v` (check), `rocq compile ExtractSpec2.v`
  (extraction of `run_case count passes fuel0` to `spec2.ml`, with
  `Tables.fold_of` and `Tables.in_prop` bound to the compiled table
  module by `Extract Constant`, so `spec2.ml` holds no table code:
  27,910 bytes), and `ocamlfind ocamlopt -c spec2.mli spec2.ml`. The
  check and the extraction load `Tables.vo`, which is included.
- Lean 4 (`lean/lean2.sh tspec`): untimed, `lean Tables.lean` to its
  `.olean`. Timed: `lean -R . Spec2.lean` (check),
  `lean ... -c Spec2.c` (elaboration and C emission), and
  `leanc -c -O3 -DNDEBUG Spec2.c`.
- Why3 and F\*: as run 1's [T_spec entry](2026-11-24-exp-06-m2-t-spec.md)
  (`why3_2.sh tspec`, `fstar2.sh tspec`).

## Analysis

- Why3 and F\* reproduce run 1's `T_spec` within 0.02 s. DEV-008's
  one-line change costs nothing measurable.
- Rocq's and Lean's S2 semantics (412 and 335 lines, 1.9x and 2.0x
  milestone 1's) build 2.6x and 1.8x slower than milestone 1's. As in
  run 1, part of each figure is table handling: Rocq's check and
  extraction load `Tables.vo` (built from a 1.1 MB source), and F\*'s
  extraction and compile include the table code (run 1's entry). These
  are upper bounds of the semantics' own cost, which works in favour of
  settling targets "in-prover".
- Building the table module itself, untimed here, again dominates F\*:
  24 s, against 7.9 s for its semantics.
